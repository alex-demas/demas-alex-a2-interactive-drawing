# Cookie Monster Instructions
Hi! Here are the instructions to interact with Cookie Monster:
1. **Drag** the Cookie around the screen using the mouse. Cookie Monster's eyes will follow the cookie as you move it!
2. When **dragging** the Cookie over the Cookie Monster's mouth, it will open.
3. If you **Left Mouse Click** the Cookie while it's over Cookie Monster's mouth, he will eat the cookie and hide!
4. **Left Mouse Click** again to get another cookie and repeat the process.
5. Press **B** to toggle blinking, if it is hard on your eyes.

Thanks!
